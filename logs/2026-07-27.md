# Day 1 — 2026.07.27

**목표 확정**
업비트 시세를 매시간 자동 수집 → MySQL 적재 → 일별 집계 테이블 생성

## 한 것

- 업비트 Quotation API 호출 성공 (200)
- `GET /v1/ticker?markets=KRW-BTC` — 인증키 불필요
- `response.json()`으로 파싱

## 배운 것

| 에러                                       | 원인                                        | 해결              |
| ------------------------------------------ | ------------------------------------------- | ----------------- |
| `module 'requests' has no attribute 'get'` | 파일명이 `requests.py` → 자기 자신을 import | 파일명 변경       |
| 출력이 `<bound method ...>`                | 괄호 누락                                   | `response.json()` |

## 결정

- **DB: MySQL** — 익숙한 도구로 마찰 최소화. Postgres 전환은 후반 과제로
- **소스: 업비트** — 인증 불필요, 초 단위 변동
